# ACLFUTURE Music 1.4 Beta — Android

Esta versão experimental utiliza NewPipeExtractor (GPLv3) para busca e extração de streams de áudio do YouTube Music, além do catálogo global, Brave e músicas livres.

**Atenção:** o YouTube pode alterar os seus sistemas e interromper as buscas ou a reprodução. Os testes simulados não comprovam reprodução real no aparelho. O download de gravações comerciais não foi habilitado; a biblioteca offline funciona para arquivos pessoais e fontes que autorizam download.

Código-fonte disponibilizado neste repositório. Licença GNU GPL-3.0 disponível no arquivo LICENSE-GPL-3.0.txt. A integração depende da biblioteca NewPipeExtractor, independente do ACLFUTURE.

Pacote beta separado: com.aclfuture.music.preview14.
